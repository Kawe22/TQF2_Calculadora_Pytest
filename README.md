# TQF 2 Extra - Testes Unitários com Pytest

Atividade da disciplina de **Fundamentos de Quality Assurance**.

Projeto desenvolvido em Python com uma classe `Calculadora` contendo:

* Adição
* Subtração
* Multiplicação
* Divisão
* Fatorial
* Potência

Os testes unitários foram implementados com **Pytest**, incluindo cenários com números positivos, negativos, zero, valores decimais e tratamento de exceções.

## Executar o projeto

Instalar as dependências:

```bash
pip install -r requirements.txt
```

Executar os testes:

```bash
pytest -v
```
